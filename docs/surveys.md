# Surveys (identified by participant ID only; no names or emails)

## Pre-survey
1. Participant ID
2. Year of study and branch
3. How often do you use AI tools for coding? (never / monthly / weekly / daily)
4. How comfortable are you writing programs yourself? (not at all / somewhat / comfortable)
5. How would you rate your skill at writing prompts for AI tools? (1 to 5)
6. Which AI tools have you used? (free text)

## Post-survey
1. Participant ID
2. Overall, how useful was the assistant? (1 to 5)
3. When the assistant asked questions, did they help? (1 to 5, or "it never asked")
4. Did the questions annoy you? (1 to 5, or "it never asked")
5. Did you feel the assistant understood what you wanted? (1 to 5)
6. Anything else you'd like to tell us? (free text; please don't include personal details)

Per-task satisfaction (1 to 5) is collected in the session tool.
